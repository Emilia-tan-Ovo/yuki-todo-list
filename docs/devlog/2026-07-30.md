### Spring Boot MockMvc

MockMvc 会经过 Spring MVC 的请求映射、JSON 转换、参数校验和异常处理，但不需要真正启动服务器。@SpringBootTest 默认使用模拟 Web 环境，配合 @AutoConfigureMockMvc 即可测试完整 Spring 应用链路
