## 理解与笔记

### Git 提交时机

> 当一批改动可以用一句清楚的话命名，并且已经能够构建或运行时，就可以作为一个阶段提交。

### 垂直业务闭环

```text
按照真实页面开发
→ 页面调用对应接口
→ 使用 Network 联调
→ 测试通过后提交
```

### Vue 响应式数据

```text
JavaScript 中使用 ref → 通常通过 .value 读取或修改
template 中使用 ref → Vue 自动解包，不写 .value
```

### 登录请求流程

```text
填写表单
→ v-model 保存输入
→ 提交后调用 Fetch
→ 成功后跳转页面
→ 失败时展示后端 message
→ finally 恢复按钮状态
```
