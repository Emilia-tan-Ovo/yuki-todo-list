### 查询课程归属

查询指定课程时，需要同时限制课程编号和当前用户：

```java
findByIdAndUser_Id(courseId, userId)
```

这样课程不存在或属于其他用户时，都可以统一返回：

```text
404 COURSE_NOT_FOUND
```

不会泄露其他用户的数据。

### Optional

`Optional<Course>` 表示查询结果可能存在，也可能为空。

```java
courseRepository.findByIdAndUser_Id(courseId, userId)
        .orElseThrow(CourseNotFoundException::new);
```

查询不到课程时，由 Service 抛出业务异常，再交给全局异常处理器转换成 HTTP 响应。

### 修改课程时排除自己

修改课程名称时，查重不能把当前课程本身算进去：

```java
existsByUser_IdAndNameIgnoreCaseAndIdNot(
        userId,
        name,
        courseId
);
```

因此：

- 名称不变可以成功
- 只改变大小写可以成功
- 与另一门课程重名时返回 `409`

### ON DELETE CASCADE

数据库外键提前配置：

```sql
ON DELETE CASCADE
```

删除课程后，MySQL 会自动删除该课程下的关联任务，不需要在 Java 中逐条删除。

### 固定测试规则

接口测试只使用：

- `mysql.exe`
- PowerShell `Invoke-WebRequest`
- `WebRequestSession`

禁止 Codex 临时创建 Java、JDBC、Python 或 PowerShell 辅助程序。指定工具不可用时停止并汇报，不再自行寻找替代方案。
