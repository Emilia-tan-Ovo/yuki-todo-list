## 理解与笔记

### Vue 页面基本结构

```text
<script setup> → 数据和操作
<template>     → 页面内容
<style>        → 页面外观
```

### 当前课程详情数据流

```text
点击课程卡片
→ 进入 /courses/:courseId
→ 获取 courseId
→ 请求 GET /api/courses/{courseId}
→ 将结果保存到 course
→ 页面展示课程信息
```
