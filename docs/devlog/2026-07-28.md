## 理解 / 笔记

### Session

登录或注册成功后，后端把用户编号保存到 Session：

```java
session.setAttribute("userId", response.getId());
```

获取已有 Session：

```java
HttpSession session = request.getSession(false);
```

含义：

```text
已有 Session → 返回 Session
没有 Session → 返回 null
不会新建 Session
```

获取当前用户编号：

```java
Long userId = (Long) session.getAttribute("userId");
```

退出登录：

```java
session.invalidate();
```

Session 通常在主动退出、超时或服务器重启后失效。关闭浏览器后，Session Cookie 可能消失，但服务器端 Session 不一定立即删除。

### 全局异常处理

只抛出异常还不够，需要在 `GlobalExceptionHandler` 中转换成 HTTP 响应。

```text
抛出 UnauthorizedException
→ GlobalExceptionHandler 捕获
→ 返回 401 UNAUTHORIZED
```

如果没有对应的异常处理方法，可能会返回 `500 Internal Server Error`。

### trim()

`trim()` 用于去掉字符串开头和结尾的空格：

```text
"  JavaWeb  "
→
"JavaWeb"
```

创建课程时先 `trim()`，可以避免下面两个名称被当成不同课程：

```text
JavaWeb
JavaWeb 
```

### 忽略大小写查重

同一个用户已有：

```text
JavaWeb
```

再次提交：

```text
 javaweb 
```

经过 `trim()` 和忽略大小写查重后，会判断为重复并返回 `409`。
