## 理解与笔记

### Vue 功能代码的阅读顺序

1. 在 `template` 中找到按钮或表单绑定的事件。
2. 查看事件调用了哪个函数。
3. 在 `<script setup>` 中找到对应函数。
4. 查看函数调用了哪个 API 方法。
5. 去 `api/*.js` 中确认请求地址和请求方式。

简单记忆：

```text
template → 触发事件
script setup → 处理业务
api/*.js → 请求后端
```

今天没有系统掌握新的前端知识，主要记住了这条阅读路线。
