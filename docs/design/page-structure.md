# YuKi's TODO List 页面结构设计

## 1. 设计目标

YuKi's TODO List 是一款面向大学生、以课程为中心的个人学习任务管理工具。

首版页面设计遵循以下原则：

- 保持界面简洁；
- 减少不必要的输入；
- 以课程组织学习任务；
- 优先展示最近截止的任务；
- 同时适配电脑和手机浏览器；
- 首版不开发原生手机 App。

## 2. 整体页面结构

首版包含以下页面和交互窗口：

1. 登录页；
2. 注册页；
3. 首页；
4. 课程详情页；
5. 新建/编辑课程窗口；
6. 新建/编辑任务窗口。

首版不单独设计任务详情页。用户点击任务后，直接展开任务操作区域或进入编辑窗口。

## 3. 响应式设计

系统采用响应式 Web 页面。

- 电脑端一行展示多张课程卡片；
- 手机浏览器一行展示一张课程卡片；
- 电脑端和手机端共用同一套前后端系统；
- 后续可以考虑升级为 PWA，但不属于首版范围。

## 4. 登录页

登录页包含：

- 用户名或邮箱；
- 密码；
- 登录按钮；
- 前往注册页的入口。

登录成功后进入系统首页。

## 5. 注册页

注册页包含：

- 用户名；
- 邮箱；
- 密码；
- 确认密码；
- 注册按钮；
- 返回登录页的入口。

## 6. 首页

首页以课程卡片为核心。

顶部区域包含：

- 系统名称；
- 当前用户信息；
- 新建任务入口；
- 新建课程入口；
- 退出登录入口。

每张课程卡片展示：

- 课程名称；
- 课程颜色；
- 未完成任务数量；
- 最近截止的三项未完成任务；
- 任务截止日期；
- 查看课程详情入口。

课程卡片按照课程创建时间从早到晚排列，创建时间越早，列表位置越靠前。

首页创建任务时，用户需要选择所属课程。

首页点击课程卡片中的任务后，直接打开任务编辑窗口。

```text
------------------------------------------------

```

## 7. 课程详情页

课程详情页包含：

- 返回首页入口；
- 课程名称；
- 编辑课程入口；
- 新建任务入口；
- 未完成任务标签；
- 已完成任务标签。

默认展示“未完成任务”。

未完成任务按照截止日期由近到远排序。

任务首版只包含两种状态：

- TODO：未完成；
- DONE：已完成。

课程详情页点击某项任务后，展开任务操作区域，展示：

- 任务名称；
- 所属课程；
- 截止日期；
- 当前状态；
- 编辑任务入口；
- 删除任务入口。

用户可以通过状态选择将任务改为“已完成”。

任务完成后：

- 从未完成任务列表中移出；
- 进入当前课程的已完成任务列表；
- 数据仍然保留，不直接删除。

### 页面示例

```text
------------------------------------------------

← 返回首页

JavaWeb                         [编辑课程]

[TODO 3]  [DONE 8]          [+ 新建任务]

────────────────────────────────

(任务默认只展示最必要的信息：)

完成页面结构设计                 7 月 24 日

(点击任务后，卡片向下展开：)

设计数据库                       7 月 26 日
────────────────────────────────
所属课程：JavaWeb
截止日期：2026-07-26
状态：[TODO ▼]

(点击状态下拉框：)

状态：[DONE ▼]

      TODO
      DONE

[编辑任务]                [删除任务]

编写登录接口                     7 月 30 日

------------------------------------------------
```

## 8. 新建/编辑课程窗口

课程窗口采用居中的卡片弹窗。

新建课程时包含：

- 课程名称；
- 自动分配的课程颜色；
- 取消按钮；
- 保存按钮。

课程名称为必填项。

系统自动为课程分配颜色，用户可以选择是否更换颜色。

编辑课程时允许修改：

- 课程名称；
- 课程颜色。

首版不包含任课教师、上课地点和课程时间等信息。

### 页面示例

```text
------------------------------------------------

┌──────────────────────────┐
│ 新建课程              ×  │
│                          │
│ 课程名称 *               │
│ [请输入课程名称        ] │
│                          │
│ 课程颜色                 │
│ [系统自动分配] [更换颜色]│
│                          │
│        [取消]  [保存]     │
└──────────────────────────┘

------------------------------------------------
```

## 9. 新建/编辑任务窗口

新建任务时包含：

- 任务名称；
- 所属课程；
- 截止日期；
- 取消按钮；
- 保存按钮。

以上三个字段均为必填项。

从课程详情页创建任务时，系统自动填入当前课程。

系统自动设置：

- 状态为TODO；
- 创建时间为当前时间；
- 更新时间为当前时间。

编辑任务时允许修改：

- 任务名称；
- 所属课程；
- 截止日期；
- 任务状态。

编辑窗口提供删除任务入口。删除前必须经过二次确认。

### 页面示例

```text
------------------------------------------------

┌──────────────────────────┐
│ 新建任务              ×  │
│                          │
│ 任务名称 *               │
│ [请输入任务名称        ] │
│                          │
│ 所属课程 *               │
│ [JavaWeb              ▼] │
│                          │
│ 截止日期 *               │
│ [2026-07-30           📅] │
│                          │
│        [取消]  [保存]     │
└──────────────────────────┘

------------------------------------------------
```

## 10. 页面跳转流程

用户完成注册或登录后进入首页。

用户可以在首页：

- 查看课程卡片；
- 创建课程；
- 创建任务；
- 点击课程进入课程详情页。

进入课程详情页后，用户可以：

- 查看未完成任务；
- 查看已完成任务；
- 创建任务；
- 编辑任务；
- 修改任务状态；
- 删除任务；
- 编辑课程。

## 11. 暂不实现

首版暂不实现：

- 原生手机 App；
- 任务详情独立页面；
- 子任务；
- 任务描述；
- 优先级；
- 预计耗时；
- AI 自动拆解；
- 消息提醒；
- 日历视图；
- 自动导入课程表。
