# 校园学习任务管理器——项目概述与首版功能范围

## 一、项目背景

大学生在日常学习中需要同时处理多门课程的作业、实验、课程设计、考试复习等任务。由于任务来源分散、截止时间不同，学生容易出现任务遗漏、安排混乱以及不知道下一步应该完成什么的问题。

本项目计划开发一款面向大学生的校园学习任务管理器，通过课程和任务之间的关联，帮助用户集中记录、整理和查看学习任务，从而更清楚地掌握每门课程当前需要完成的事项。

## 二、目标用户

本项目的主要目标用户为在校大学生。

用户可以根据自己的课程情况创建课程，并在对应课程下记录作业、实验、复习计划、课程设计等学习任务。

## 三、产品定位

本项目是一款以课程为中心的个人学习任务管理工具。

系统不追求复杂的学习计划安排，而是通过简洁的课程卡片和任务列表，帮助用户快速回答以下问题：

1. 当前有哪些课程？
2. 每门课程还有哪些任务没有完成？
3. 最近需要完成的任务是什么？
4. 哪些任务已经完成？

## 四、设计原则

### 1. 保持简洁

创建任务时只要求用户填写必要信息，减少不必要的操作。

### 2. 以课程组织任务

任务必须归属于一门课程，避免所有任务混合在同一个列表中，使用户能够按照课程梳理学习内容。

### 3. 优先展示近期任务

首页不展示每门课程的全部任务，只展示最近截止的若干项任务，避免信息过多。

### 4. 完成不等于删除

已经完成的任务不会被直接删除，而是归档到对应课程的“已完成任务”页面，方便用户查看历史记录。

## 五、核心使用流程

用户注册或登录系统后进入首页。

首页以课程卡片的形式展示用户创建的课程。每张课程卡片展示课程名称、课程颜色、未完成任务数量以及最近截止的三项任务。

用户可以点击课程卡片进入课程详情页，查看该课程下的全部未完成任务和已完成任务。

用户可以创建、修改、删除任务，并根据实际学习进度修改任务状态。

任务完成后，将从未完成任务列表中移出，并归档到该课程的已完成任务页面。

## 六、首版核心功能

### 1. 用户管理

* 用户注册
* 用户登录
* 用户退出登录
* 用户只能访问自己的课程和任务数据

### 2. 课程管理

* 创建课程
* 查看课程列表
* 修改课程名称
* 删除课程
* 系统为新课程自动分配一个默认颜色
* 用户后续可以选择是否修改课程颜色

首版课程信息主要包括：

* 课程名称
* 课程颜色
* 创建时间

任课教师不属于首版必要信息，因此暂不添加。

### 3. 任务管理

* 创建任务
* 查看任务
* 修改任务
* 删除任务
* 修改任务状态
* 按所属课程查看任务
* 按截止日期排列任务

创建任务时需要填写：

* 任务标题
* 所属课程
* 截止日期

系统自动记录：

* 初始状态：待完成
* 创建时间
* 更新时间

首版任务状态包括：

* 待完成
* 进行中
* 已完成

### 4. 首页课程卡片

首页以课程卡片为主要内容。

每张课程卡片展示：

* 课程名称
* 课程颜色
* 未完成任务数量
* 最近截止的三项未完成任务
* 最近任务的截止日期
* 查看全部任务入口

当课程任务较多时，用户可以点击课程卡片进入课程详情页查看完整内容。

### 5. 已完成任务归档

任务状态修改为“已完成”后：

* 任务从未完成任务列表中移出
* 任务保留在数据库中
* 任务进入对应课程的已完成任务页面
* 用户可以查看之前完成过的任务

## 七、首版暂不实现的功能

为控制第一个 JavaWeb 项目的开发范围，以下功能暂不纳入首版：

* 自动导入学校课程表
* 对接教务系统
* 课程具体上课时间管理
* 任课教师信息管理
* 子任务拆分
* AI 自动拆解任务
* AI 推荐下一步任务
* 消息推送
* 多人协作
* 教师发布作业
* 成绩管理
* 文件上传

这些功能可以作为项目后续版本的扩展方向。

## 八、后续扩展设想

在基础版本稳定后，可以逐步加入：

1. 将大型学习任务拆分为多个子任务；
2. 根据任务截止日期和完成情况推荐下一步行动；
3. 使用 AI 帮助用户分析和拆解复杂任务；
4. 增加周视图或日历视图；
5. 支持课程表文件导入；
6. 增加学习任务完成统计。

## 九、首版验收目标

当用户能够完成以下完整流程时，可以认为项目首版核心功能已经实现：

1. 注册并登录系统；
2. 创建一门课程；
3. 在课程下创建学习任务；
4. 在首页看到该课程最近截止的任务；
5. 查看课程下的全部任务；
6. 修改任务内容和状态；
7. 将任务标记为已完成；
8. 在已完成任务页面找到该任务；
9. 不同用户之间的数据相互隔离。
